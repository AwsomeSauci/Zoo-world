# Zoo World

3D-симуляция пищевой цепочки с видом сверху. Лягушки прыгают, змеи движутся непрерывно. Каждые 1–2 секунды появляется одно животное. Жертвы отскакивают друг от друга, хищники поедают животных при контакте. uGUI показывает счётчики погибших и `Tasty!` под хищником.

[Играть в браузере](https://AwsomeSauci.github.io/Zoo-world/)

## Запуск

Нужны **Unity 6000.6.0f1** и **Git** для восстановления пакетов. Откройте проект, затем сцену **Assets/Scenes/Zoo.unity** и нажмите Play.

Основные настройки находятся в **Assets/Configurations/Zoo Settings.asset**: состав видов, веса появления, интервал спавна и seed. Параметры движения и питания лежат в соседних папках.

## Проверки и сборка

- Тесты: **Window → General → Test Runner**, вкладки EditMode и PlayMode.
- Проверки из PowerShell: `./Tools/Verify.ps1`.
- Локальная сборка WebGL: `./Tools/Build-Web.ps1`; в Unity нужен модуль Web Build Support.
- GitHub Actions собирает WebGL при изменениях в `main` или ручном запуске и публикует игру в GitHub Pages.

## Архитектура

- **Domain** — правила питания, выбор направления и способы перемещения.
- **Application** — экземпляры животных, фабрики модулей, спавн, контакты и статистика.
- **Unity** — Rigidbody, пулы тел, камера и uGUI.
- **Composition** — настройки ScriptableObject и привязки Extenject.

Domain и Application не зависят от Unity. Животное собирается из модулей движения и питания; каждый экземпляр получает собственное состояние. Выбор направления отделён от способа перемещения. **Extenject** связывает зависимости, **R3** передаёт статистику и события поедания в UI.

## Новый вид

1. Создать prefab на основе Frog или Snake: единичный масштаб корня, динамический Rigidbody без гравитации и damping, замороженные Y и вращение. На корне — один SphereCollider, BoxCollider или CapsuleCollider и слой Animal; модель — под Visual.
2. Создать **Create → Zoo World → Animal**, задать уникальный Species ID, prefab и модули движения и питания.
3. Добавить вид в Zoo Settings с положительным весом. Например, Jumping Movement и Predator дают прыгающего хищника без изменения кода.

Новые механики добавляются через `ILocomotionBehaviour` / `LocomotionAsset`, `ISteeringBehaviour` / `SteeringAsset` или `IAnimalModule` / `AnimalModuleAsset`.

## Правила

- При встрече хищников выживает животное с меньшим ID появления.
- Симуляция идёт в плоскости XZ; высота прыжка относится к модели. Камера ортографическая, направлена сверху вдоль осей мира.
- Животные возвращаются в границы камеры и пробуют боковой обход при застревании. Это локальное поведение, без поиска пути по лабиринту.
